MC Java版如何制作标题全景图

Zarijaden
  2026-08-06 2026-08-06 创建   2026-09-05 03:16:39 2026-09-05 03:16:39 更新  
  • MC 
 1.1k 字  

前言

我玩的Neoforge，虽然是新兴的加载器，但是实际上已经有不少一键截图的mod了
PixelShotBetter Panorama
问题是这两个mod在我的电脑上都有问题。。。截出来的图是纯色背景，我只能古法截图了

还没开始

虽说真正的古法截图是不需要那么多操作，直接冻结时间，tp，截图就好了，但说实话有资源我想用起来，自由度更大。
还没开始，先说说真正的古法截图吧。

第一步

先在启动器里面给窗口设置好大小，一定要是正方形

第二步

进入存档，把视场角调成90°（90x4=360就是一圈），用指令冻结时间/tick freeze注意这个指令在23w43a时才加入，1.20.3之前是用不了的。不过影响不大，只是到时候结果可能会有些地方错位而已。有需要可以把能关的动画都关掉
然后按照以下指令tp后按f2截图（小tip：可以tp完之后按f1隐藏UI防止tp信息干扰）
/tp @s ~ ~ ~ 0 0
/tp @s ~ ~ ~ 90 0
/tp @s ~ ~ ~ 180 0
/tp @s ~ ~ ~ -90 0
/tp @s ~ ~ ~ 0 -90
/tp @s ~ ~ ~ 0 90
好吧我承认自己能力不足。这些我上网跟教程做了一遍结果还是中间有接缝，看样子是视场角问题，但网上也有90°的出来效果很好。

第三步

打开截图文件夹，按上面的顺序，依次将图片命名为panorama_0 panorama_1 panorama_2 panorama_3 panorama_4 panorama_5留意好是6张图，第一张是0结尾的
ok你已经完成了古法截图特别的地方了，接下来放进资源包的内容往下翻吧

开始

哎呀终于开始啦哈哈
来吧，先下载replay.replay在不同加载器，不同版本下，官方和各个分支及其混乱。我本来想用表格梳理，最后发现太难了，有需要自己去找吧

第一步

进存档，录一小段replay。出来保存之后进编辑。选好时间点，打上两种关键帧，总共两个时间点，相隔不超过1秒（当然你想要多几张也可以多于一秒）
小tips：

  • 打关键帧的快捷键是i和o，分别对应两种关键帧
  • 视角尽量正视前方，否则导出的照片也是歪的
  • 调出鼠标的快捷键直接对应打开聊天框的快捷键

第二步

点渲染按钮，按照图片设置。分辨率可以自选，图中对应2k，注意后面的数得是3的倍数

开始渲染后可能会出现内存不够卡退或者卡死的情况，只要有了3张图以上就可以取消渲染了。
打开replay_videos文件夹，找到刚刚输出的文件夹，选一个效果最好的（一般来说都是一样的，选最后一张）

第三步

这一步可能会劝退不少人吧，要用到PS。有就用，没有只能找其他办法了，切个图应该不用太复杂。




下图注意：要选PNG-24；想保持画质就选“原稿”选项卡，默认是“优化”；看不到全图就在左下角调；要用切片工具；可以按住shift选切片，但是实测好像不符合预期；最后点储存

下图注意：除了选择路径，如果乱动其他按钮很有可能会输出.gif图片，确认好上一步选了PNG-24就好了，最后按保存

按照图片逐步操作就可以了。

第四步

现在已经获得6张带有内容的图片，其他删掉。
这六张按照下表重命名

无内容panorama_4无内容无内容
panorama_3panorama_0panorama_1panorama_2
无内容panorama_5无内容无内容

第五步

最后一步，把6张图片放进资源包/assets/minecraft/textures/gui/title/background

如果是如图中后缀名是.gif的，要用格式转换器转成.png直接改后缀名没试过，盲猜不行

结尾

好了，现在你已经做好一个资源包了。。。。吗？
并不，你现在只是有了资源，还没变成“包”。秘诀在这儿：pack.mameta。有了这个文件，mc才会认定你这个是一个资源包，以下是最简洁的示例

最后可以加上pack.png作为封面，就完工了
可以选择打包成.zip压缩包，也可以直接把文件夹放在那儿。
